# TASKS/014.1-battle-speed-control.md

## 任务目标

在战斗界面增加倍速控制按钮，支持玩家在 1x / 2x / 3x / 4x 之间循环切换。倍速只影响战斗流程，不影响主界面和非战斗系统。

## 背景说明

当前战斗以固定 1x 速度运行，玩家无法加速战斗。需要增加倍速控制，让玩家可以加快战斗节奏。

当前时间系统分析：
- `GameBootstrap.update(deltaTime)` 是唯一入口，传给 `BattleManager.update(deltaTime)`
- `BattleManager` 内部统一分发 `deltaTime` 给 `TimeManager`、`EnemySpawner`、`TowerManager`
- Cocos 组件层（`AttackEffectView`、`TowerView`、`BattleVisualManager`）由引擎直接调用 `update(deltaTime)`
- `RogueChoiceManager.update(currentTime)` 使用战斗时间，不直接用 deltaTime

因此倍速控制的切入点是 `BattleManager.update()`，将 `deltaTime` 乘以倍速后统一分发。Cocos 组件层需要额外接入倍速。

## 实现计划

### 1. EventBus 新增事件

在 `BATTLE_EVENTS` 中新增：

```typescript
BATTLE_SPEED_CHANGE: 'battle:speed_change',
```

### 2. BattleManager 增加倍速管理

新增字段和方法：

```typescript
/** 当前战斗倍速 */
private _battleSpeed: number = 1;
/** 可选倍速列表 */
private readonly SPEED_OPTIONS: number[] = [1, 2, 3, 4];

/** 获取当前倍速 */
getBattleSpeed(): number { return this._battleSpeed; }

/** 设置倍速 */
setBattleSpeed(speed: number): void {
    if (this.SPEED_OPTIONS.includes(speed)) {
        this._battleSpeed = speed;
        this._eventBus.emit(BATTLE_EVENTS.BATTLE_SPEED_CHANGE, { speed });
    }
}

/** 循环切换倍速 */
cycleBattleSpeed(): void {
    const currentIndex = this.SPEED_OPTIONS.indexOf(this._battleSpeed);
    const nextIndex = (currentIndex + 1) % this.SPEED_OPTIONS.length;
    this.setBattleSpeed(this.SPEED_OPTIONS[nextIndex]);
}
```

修改 `update()` 方法：

```typescript
update(deltaTime: number): void {
    if (this._state !== 'playing') return;
    if (this._isForcePaused || this._isPlacementPaused) return;

    // 应用倍速
    const scaledDeltaTime = deltaTime * this._battleSpeed;

    // 使用 scaledDeltaTime 驱动战斗逻辑
    this._timeManager.updateBattleTime(scaledDeltaTime);
    const currentTime = this._timeManager.getBattleTime();

    this._rogueChoiceManager.update(currentTime);

    if (this._enemySpawner) {
        this._enemySpawner.update(scaledDeltaTime, currentTime);
    }

    if (this._towerManager && this._enemySpawner) {
        const aliveEnemies = this._enemySpawner.getAliveEnemies();
        this._towerManager.update(scaledDeltaTime, aliveEnemies);
    }
}
```

`startBattle()` 和 `returnToIdle()` 中重置倍速为 1。

### 3. Cocos 组件层接入倍速

**AttackEffectView.ts**：
- 缓存倍速值，监听 `BATTLE_SPEED_CHANGE` 事件
- `update()` 中使用 `deltaTime * this._battleSpeed` 更新特效生命周期

**TowerView.ts**：
- 缓存倍速值，监听 `BATTLE_SPEED_CHANGE` 事件
- `update()` 中使用 `deltaTime * this._battleSpeed` 更新闪烁计时器

**BattleVisualManager.ts**：
- 缓存倍速值，监听 `BATTLE_SPEED_CHANGE` 事件
- `update()` 中使用 `deltaTime * this._battleSpeed` 更新敌人位置同步（如果使用了 deltaTime）

### 4. BattleUI 动态创建倍速按钮

在 `BattleUI` 中动态创建倍速按钮，复用现有动态面板创建模式：

- 位置：技能按钮旁边或战斗 HUD 右上角
- 按钮文本：`倍速 x1` / `倍速 x2` / `倍速 x3` / `倍速 x4`
- 点击逻辑：调用 `BattleManager.cycleBattleSpeed()`，更新按钮文本
- 监听 `BATTLE_SPEED_CHANGE` 事件同步更新按钮文本
- 战斗开始时默认显示 `倍速 x1`
- 放置阶段隐藏倍速按钮

## 倍速影响范围

倍速通过 `scaledDeltaTime` 影响以下内容：

| 系统 | 影响方式 | 接入方式 |
|---|---|---|
| 战斗倒计时 | 时间推进加速 | BattleManager → TimeManager |
| 敌人移动 | 移动速度加快 | BattleManager → EnemySpawner → EnemyController |
| 敌人生成 | 生成计时器加速 | BattleManager → EnemySpawner |
| 塔攻击冷却 | 冷却加速 | BattleManager → TowerManager → TowerController |
| 投射物飞行 | 飞行速度加快 | BattleManager → TowerManager → ProjectileManager |
| 减速持续时间 | 减速时间加速消耗 | EnemyController（使用 deltaTime） |
| 攻击特效生命周期 | 特效播放加速 | AttackEffectView（需接入） |
| 塔闪烁反馈 | 闪烁加速 | TowerView（需接入） |

倍速通过 `currentTime`（战斗时间）间接影响：

| 系统 | 影响方式 | 接入方式 |
|---|---|---|
| 肉鸽触发时间 | 提前触发 | BattleManager → RogueChoiceManager |

## 倍速不影响范围

| 系统 | 原因 |
|---|---|
| 主菜单 UI | 不在战斗 update 链路中 |
| 按钮点击响应 | Cocos 引擎事件，不受 deltaTime 影响 |
| 设置界面 | 非战斗状态 |
| 离线收益计时 | GameBootstrap 中独立 update |
| Cocos 编辑器 | 不修改 .scene |

## UI 方案

倍速按钮动态创建，不修改 `.scene`：

- 创建位置：BattleUI 节点下，技能按钮区域附近
- 按钮大小：约 100×40 像素
- 背景色：深蓝色，与其他战斗 UI 风格一致
- 文字颜色：白色
- 文字内容：`倍速 x1` / `倍速 x2` / `倍速 x3` / `倍速 x4`
- 点击事件：调用 `BattleManager.cycleBattleSpeed()`

## 验收标准

Web 预览人工验收：

1. 战斗界面出现倍速按钮
2. 默认显示 `倍速 x1`
3. 点击后依次切换 `x2` / `x3` / `x4` / `x1`
4. x2 时战斗明显加快（敌人移动、塔攻击、倒计时同步）
5. x3 时战斗继续稳定
6. x4 时所有战斗系统同步加快
7. 切换倍速不会导致敌人卡住
8. 切换倍速不会导致塔不攻击
9. 切换倍速不会导致肉鸽触发错乱
10. 切换倍速不会导致结算异常
11. 返回主界面后倍速不影响主界面
12. 重新进入战斗默认回到 x1
13. 未修改 `.scene`
14. 未修改战斗数值配置

## 测试方式

1. 在 Cocos Creator 中运行 Web 预览
2. 进入战斗，确认默认显示 `倍速 x1`
3. 点击倍速按钮，确认切换到 `x2`
4. 观察敌人移动速度、塔攻击频率、倒计时是否同步加快
5. 继续切换到 `x3`、`x4`，确认所有系统稳定
6. 切换回 `x1`，确认恢复正常速度
7. 结束战斗回到主界面，确认主界面不受影响
8. 重新进入战斗，确认默认 `x1`
9. 在 x2/x3 下触发肉鸽选择，确认暂停/恢复正常
10. 在 x2/x3 下使用技能，确认技能效果正常

## 风险点

1. Cocos 组件层 update 不受 BattleManager 控制 — 缓解：通过 EventBus 通知 + 内部缓存倍速
2. 切换倍速时肉鸽选择正在暂停 — 缓解：暂停期间 scaledDeltaTime 不生效（已有 isForcePaused 守卫）
3. x4 倍速下大量敌人时性能 — 缓解：观察，非阻塞，后续可优化
4. 放置阶段倍速应无效 — 缓解：isPlacementPaused 守卫已存在
