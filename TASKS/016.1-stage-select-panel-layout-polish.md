# 016.1 关卡选择面板布局优化

## 任务目标

优化 StageSelectPanel 的动态 UI 布局，解决标题、返回按钮、关卡按钮重叠问题，使面板清晰可读。

---

## 背景说明

016 关卡选择动态面板已经能打开，但 Web 预览中 UI 很乱：
1. 标题、返回按钮、关卡按钮重叠
2. 关卡按钮之间距离太近
3. "开始挑战/未解锁"和关卡标题、描述挤在一起
4. 面板没有清晰容器边界

**问题根因：**
1. `_createUI()` 使用 `panelWidth` 和 `panelHeight`（来自 StageSelectPanelRoot 的 UITransform），但容器节点没有设置明确的 contentSize
2. 标题位置依赖外部节点尺寸，不可控
3. 关卡按钮内部文字位置计算不合理

## 实现步骤

### 步骤 1：定义固定容器尺寸和布局常量

```typescript
// 容器尺寸
private readonly PANEL_WIDTH = 560;
private readonly PANEL_HEIGHT = 980;

// 标题区域
private readonly TITLE_Y = 420;
private readonly TITLE_FONT_SIZE = 36;

// 返回按钮
private readonly BACK_BTN_Y = 360;
private readonly BACK_BTN_WIDTH = 160;
private readonly BACK_BTN_HEIGHT = 56;

// 关卡按钮列表
private readonly STAGE_LIST_START_Y = 260;
private readonly STAGE_BTN_HEIGHT = 100;
private readonly STAGE_BTN_GAP = 20;
private readonly STAGE_BTN_WIDTH = 480;
private readonly MAX_VISIBLE_STAGES = 6;

// 关卡按钮内部文字
private readonly STAGE_TITLE_Y = 24;
private readonly STAGE_TITLE_FONT = 26;
private readonly STAGE_DESC_Y = -4;
private readonly STAGE_DESC_FONT = 18;
private readonly STAGE_STATUS_Y = -28;
private readonly STAGE_STATUS_FONT = 20;
```

### 步骤 2：重写 `_createUI()`

- 创建固定尺寸的 panelContainer（560 x 980）
- 绘制半透明背景
- 创建标题（y=420）
- 创建返回按钮（y=360）
- 创建关卡列表容器节点
- 创建底部提示文字（如果关卡数 > MAX_VISIBLE_STAGES）

### 步骤 3：重写 `_createStageButton()`

按钮内部文字分层：
- 关卡标题：y = +24，字号 26，左对齐
- 描述：y = -4，字号 18，左对齐
- 状态文字：y = -28，字号 20，右对齐

视觉区分：
- 已解锁：青色描边，白色文字，"点击挑战"
- 未解锁：灰色描边，灰色文字，"🔒 未解锁"

### 步骤 4：更新 `_updateStageButtons()`

- 使用新的布局常量
- 添加调试日志：`[StageSelectPanel] refresh stage count: x`
- 点击日志：`[StageSelectPanel] click stage: stage_x unlocked=true/false`

### 步骤 5：更新点击事件

- 已解锁：进入战斗
- 未解锁：只输出日志，不进入战斗

### 步骤 6：更新文档

- 更新 `CHANGELOG.md`
- 更新 `docs/handoff/CURRENT_STATE.md`

## 风险点

1. **容器尺寸固定**：如果 StageSelectPanelRoot 的 UITransform 尺寸小于 560x980，可能会被裁剪
   - 缓解：用户可以在 Cocos Creator 中调整 StageSelectPanelRoot 尺寸

2. **关卡数量超过 6 关**：当前只显示前 6 关，底部显示"更多关卡后续开放"
   - 缓解：后续可添加 ScrollView

3. **文字长度溢出**：如果关卡名称或描述太长，可能会溢出按钮
   - 缓解：限制 Label 的 contentSize，超出部分截断
