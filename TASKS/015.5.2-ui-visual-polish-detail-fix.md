# TASKS/015.5.2-ui-visual-polish-detail-fix.md

## 任务目标

在 015.5 UI 美化第一轮基础上，修复细节表现不足的问题：绑定面板优先使用 Cocos 场景节点，未绑定时保留动态 fallback；肉鸽选择面板、塔位选择面板、塔详情面板获得更清晰的卡片 / 外框层次。

## 背景说明

### 当前问题

- 015.5 只建立了基础主题和样式工具，部分面板视觉变化不够明显
- 肉鸽三选一卡片边界不清晰
- 塔位选择和塔详情需要兼容 Cocos 人工绑定面板与代码动态 fallback

### 解决方案

- `UITheme.ts` 增加卡片、ghost 按钮、数值 / 警告文字等颜色
- `UIStyleUtil.ts` 增加 `styleCard()`、`styleOuterFrame()`、`stylePanelTitle()`、`styleValueLabel()`、`styleWarningLabel()`
- `BattleUI.ts` 优先使用绑定面板，未绑定时动态创建 fallback
- 肉鸽选择面板使用 `styleOuterFrame()` 包住三选一卡片
- 绑定按钮事件保存 handler 引用，避免重复注册后无法精确解绑

## 允许修改范围

- `assets/scripts/ui/UITheme.ts`
- `assets/scripts/ui/UIStyleUtil.ts`
- `assets/scripts/ui/BattleUI.ts`
- `CHANGELOG.md`
- `docs/handoff/CURRENT_STATE.md`
- `TASKS/015.5.2-ui-visual-polish-detail-fix.md`

## 禁止修改范围

- `assets/scenes/*.scene`
- `assets/scripts/data/*`
- `assets/scripts/platform/*`
- 不修改战斗逻辑、数值配置、技能逻辑
- 不引入图片资源、第三方依赖
- 不新增 Shader / Material / RenderTexture

## 实现计划

### 1. UITheme.ts

- 增加卡片背景、卡片描边、高亮卡片颜色
- 增加 ghost 按钮颜色
- 增加数值文字、警告文字颜色

### 2. UIStyleUtil.ts

- 增加 `styleCard(cardNode, variant)`
- 增加 `styleOuterFrame(panelNode)`
- 增加 `stylePanelTitle(labelNode)`
- 增加 `styleValueLabel(labelNode)`
- 增加 `styleWarningLabel(labelNode)`
- 增强 `stylePanel()`，即使节点已有 Sprite 也绘制描边层

### 3. BattleUI.ts

- 肉鸽选择面板应用 `styleOuterFrame()`
- 肉鸽选项按钮应用 `styleCard()`
- 塔位选择面板优先使用绑定节点，未绑定时动态创建 fallback
- 塔详情面板优先使用绑定节点，未绑定时动态创建 fallback
- 取消 / 关闭按钮使用 ghost 样式
- 按钮事件记录 handler 引用，销毁时精确解绑

## 验收标准

1. 肉鸽选择面板有清晰外框，三个选项卡片边界清楚
2. 塔位选择面板绑定节点可用，未绑定时动态 fallback 可用
3. 塔详情面板绑定节点可用，未绑定时动态 fallback 可用
4. 按钮、标题、数值文字层次更清晰
5. 不修改 `.scene`
6. 不修改战斗数值
7. 不新增图片资源、依赖、Shader / Material / RenderTexture
8. 控制台无 015.5.2 相关报错

## 风险点

1. **绑定优先**：Cocos 人工绑定节点尺寸和位置仍需用户在编辑器里确认
2. **动态 fallback**：动态面板只作为兜底，不应替代人工布局
3. **按钮监听**：重复显示面板时必须避免事件重复绑定
