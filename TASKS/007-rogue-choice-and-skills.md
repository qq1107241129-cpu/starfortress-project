# TASKS/007-rogue-choice-and-skills

## 1. 任务目标

实现局内肉鸽强化选择与主动技能系统，包括每局 3 次 3 选 1、塔属性强化、轨道炮和全屏冻结。

## 2. 背景说明

自动战斗应能发挥约 80% 效果，玩家的额外上限来自局内选择和关键时刻释放主动技能。MVP 只做可验证的局内成长和 2 个主动技能。

## 3. 涉及文件

- `assets/scripts/battle/RogueChoiceManager.ts`
- `assets/scripts/battle/SkillManager.ts`
- `assets/scripts/battle/BattleManager.ts`
- `assets/scripts/battle/TowerManager.ts`
- `assets/scripts/battle/EnemyController.ts`
- `assets/scripts/data/SkillConfig.ts`
- `assets/scripts/ui/BattleUI.ts`
- `docs/GAME_DESIGN.md`
- `CHANGELOG.md`

## 4. 允许修改范围

- 新增或更新肉鸽选择管理、主动技能管理和战斗 UI 中的技能入口。
- 为塔系统和敌人系统补充必要的效果接口。
- 更新技能配置、玩法文档和变更记录。

## 5. 禁止修改范围

- 不新增 MVP 外主动技能。
- 不做复杂技能树。
- 不做广告刷新肉鸽选项的真实接入。
- 不实现完整美术特效。
- 不接平台 API。

## 6. 实现假设

- 肉鸽选择触发时间为 45 秒、90 秒、135 秒。
- 每次从配置池中抽取 3 个选项。
- 轨道炮自动锁定敌人最密集区域。
- 全屏冻结使所有敌人停止移动 2 秒。

## 7. 实现步骤

1. 在 `SkillConfig` 中定义肉鸽强化和主动技能。
2. 实现肉鸽触发计时。
3. 实现 3 选 1 选项生成。
4. 实现选择后立即生效。
5. 实现主动技能次数管理。
6. 实现轨道炮区域伤害。
7. 实现全屏冻结。
8. 在战斗 UI 暴露技能按钮和选择面板入口。
9. 更新文档与 changelog。

## 8. 验收标准

1. 战斗中能弹出肉鸽选择。
2. 选择后立即生效。
3. 主动技能按钮可点击。
4. 轨道炮能造成伤害。
5. 全屏冻结能暂停敌人移动。
6. 每局最多触发 3 次肉鸽选择。

## 9. 测试方式

- Web 预览运行一局，等待或缩短触发时间验证 3 次选择。
- 选择塔属性强化后观察塔伤害或射速变化。
- 使用轨道炮命中多敌人区域。
- 使用全屏冻结观察敌人暂停 2 秒。

## 10. 回滚方式

- 恢复 `RogueChoiceManager`、`SkillManager`、战斗 UI 和相关配置。
- 移除塔和敌人系统中本任务新增的效果接口。
- 回退文档和 changelog。

## 11. 给执行 Agent 的执行提示词

你是《星垒计划》的执行工程师。当前任务是局内肉鸽选择和主动技能。请只实现 3 次 3 选 1、配置驱动强化、轨道炮和全屏冻结。

不要新增复杂技能树、广告刷新、额外主动技能或平台功能。完成后输出 Web 预览中验证肉鸽选择与两个主动技能的方法。
