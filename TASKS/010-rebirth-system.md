# TASKS/010-rebirth-system

## 1. 任务目标

实现“星核重构”系统，包括转生条件、星核碎片计算、确认弹窗、重置与保留逻辑、5 个永久技能。

## 2. 背景说明

星核重构提供长期成长目标。MVP 只做第一轮可用的转生机制和 5 个永久技能，不做复杂星盘、稀有事件或高阶成长路线。

## 3. 涉及文件

- `assets/scripts/base/RebirthManager.ts`
- `assets/scripts/core/SaveManager.ts`
- `assets/scripts/data/RebirthConfig.ts`
- `assets/scripts/data/EconomyConfig.ts`
- `assets/scripts/ui/RebirthUI.ts`
- `docs/PRD.md`
- `docs/GAME_DESIGN.md`
- `CHANGELOG.md`

## 4. 允许修改范围

- 新增或更新星核重构管理、配置、存档和 UI。
- 补充永久技能对战斗、经营或放置的加成读取接口。
- 更新文档和变更记录。

## 5. 禁止修改范围

- 不做复杂星盘。
- 不新增超过 5 个 MVP 永久技能。
- 不新增高阶转生资源。
- 不接服务器、支付或广告。
- 不重置未授权保留字段。

## 6. 实现假设

- MVP 转生条件可为基地核心 10 级、通关第 10 关、总战力达到指定值中的一项或多项。
- 星核碎片由历史最高关卡、基地核心等级、总建筑等级、总战力计算。
- 重构后保留永久技能、星核碎片和历史记录。

## 7. 实现步骤

1. 定义星核重构条件配置。
2. 定义星核碎片计算公式。
3. 定义 5 个永久技能。
4. 实现是否可重构判断。
5. 实现确认弹窗数据。
6. 实现重置普通进度与资源。
7. 实现保留星核碎片、永久技能、历史最高记录。
8. 实现永久技能加成读取。
9. 更新文档与 changelog。

## 8. 验收标准

1. 达成条件后可星核重构。
2. 星核重构能获得星核碎片。
3. 普通资源和部分进度会重置。
4. 永久技能保留。
5. 永久技能能影响下一轮。
6. 重构前有确认弹窗。

## 9. 测试方式

- Web 预览或调试存档设置为满足条件。
- 打开重构界面，检查预计星核碎片。
- 执行重构，检查重置字段和保留字段。
- 升级永久技能，开始下一轮验证加成。

## 10. 回滚方式

- 恢复 RebirthManager、RebirthConfig、存档和 UI 改动。
- 使用备份存档恢复测试前数据。
- 回退文档和 changelog。

## 11. 给执行 Agent 的执行提示词

你是《星垒计划》的执行工程师。当前任务是星核重构系统。请只实现条件判断、星核碎片计算、确认弹窗、重置保留逻辑和 5 个 MVP 永久技能。

不要做复杂星盘、额外资源、服务器、支付或广告。完成后输出重构前后存档字段对比和 Web 验证步骤。
