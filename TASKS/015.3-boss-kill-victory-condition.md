# TASKS/015.3-boss-kill-victory-condition.md

## 任务目标

修改战斗胜利条件：不再因为 180 秒时间到达自动胜利，改为 Boss 被击杀后才胜利结算。

## 背景说明

### 当前问题

当前胜利条件只有两个触发点：
1. `TimeManager.updateBattleTime()`：时间到 180 秒 → `BATTLE_RESULT: victory`
2. `StageManager.damageBase()`：基地血量归零 → `BATTLE_RESULT: defeat`

**缺少**：Boss 死亡 → 胜利的触发点

### 当前代码结构

- `TimeManager.ts` 第77-80行：时间到自动 emit `BATTLE_RESULT: victory`
- `BattleManager.ts` 第87-91行：监听 `ENEMY_DEATH`，只记录击杀，不判断 Boss 死亡
- `EnemyController._die()`：发出 `ENEMY_DEATH` 事件，数据包含 `isBoss` 字段

## 实现计划

### 1. 修改 TimeManager.ts

删除时间到自动胜利逻辑，时间到后只停止计时：

```typescript
// 修改前（第76-80行）：
// 检查是否时间到
if (this._battleTime >= this._battleDuration) {
    this._isBattleRunning = false;
    this._eventBus.emit(BATTLE_EVENTS.BATTLE_RESULT, { result: 'victory' });
}

// 修改后：
// 时间到后停止计时，但不触发胜利（胜利由 Boss 击杀触发）
if (this._battleTime >= this._battleDuration) {
    this._battleTime = this._battleDuration;
    this._isBattleRunning = false;
}
```

### 2. 修改 BattleManager.ts

在 `_setupEventListeners()` 的 ENEMY_DEATH 监听中增加 Boss 死亡胜利判断：

```typescript
// 修改前（第87-91行）：
this._eventBus.on(BATTLE_EVENTS.ENEMY_DEATH, (data: { enemyId: string; reward: number; isBoss: boolean }) => {
    if (this._battleSettlement) {
        this._battleSettlement.recordKill(data.isBoss, data.reward);
    }
});

// 修改后：
this._eventBus.on(BATTLE_EVENTS.ENEMY_DEATH, (data: { enemyId: string; reward: number; isBoss: boolean }) => {
    if (this._battleSettlement) {
        this._battleSettlement.recordKill(data.isBoss, data.reward);
    }
    // Boss 死亡触发胜利
    if (data.isBoss && this._state === 'playing') {
        this._eventBus.emit(BATTLE_EVENTS.BATTLE_RESULT, { result: 'victory' });
    }
});
```

## 验收标准

1. 180 秒到达不会自动胜利
2. Boss 未死时战斗继续
3. Boss 死亡后立即胜利结算
4. 基地死亡仍失败结算
5. 结算奖励正常
6. 不修改 `.scene`
7. 不修改任何数值配置
8. Web 预览由用户人工确认

## 测试方式

1. 在 Cocos Creator 中运行 Web 预览
2. 进入战斗，放置塔
3. 等待 180 秒，确认不会自动胜利
4. 等待 Boss 出现（150 秒）
5. 击杀 Boss，确认立即胜利结算
6. 重新测试，让基地血量归零，确认失败结算
7. 观察控制台是否有报错

## 风险点

1. **时间到后战斗无限期继续**：如果 Boss 一直不死，战斗会无限期继续。但 Boss 血量有限，玩家最终会击杀或基地被摧毁
2. **Boss 死亡后残余敌人**：Boss 死亡后立即进入胜利结算，不等待清理残余敌人
3. **TimeManager 停止计时后 BattleManager 是否继续驱动**：BattleManager.update() 检查 `this._state === 'playing'`，不依赖 TimeManager 状态，所以不受影响
