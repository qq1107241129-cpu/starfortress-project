# TASKS/015.1-active-skill-vfx.md

## 2026-06-14 visual redo update

- Redid `assets/scripts/battle/SkillEffectView.ts` because the first 015.1 VFX looked like static debug Graphics drawings.
- Orbital cannon now uses a staged lock-on, descending beam, and impact burst sequence.
- Freeze now uses a staged snowflake burst, battlefield cold cover, frost bands, cracks, flakes, and fade-out.
- The implementation is visual-only and does not modify skill damage, freeze duration, charges, targeting, enemy movement, configs, platform APIs, images, dependencies, or `.scene`.
- VFX lifetime is now driven by `update(deltaTime)` and an internal active effect list instead of one-shot lifecycle scheduling.
- `BATTLE_END` and `onDestroy` clear active skill effect nodes.
- `SkillEffectView.ts.meta` was kept as-is and not rewritten by Codex.
- `PROJECT_MEMORY.md` has been synchronized in the 015 review fix; `TASKS/015-rogue-choice-panel-zindex-fix.md` and `assets/scenes/Battle.scene` were intentionally not modified for this redo.
- Web preview remains pending for user acceptance.

## 任务目标

为轨道炮和全屏冻结技能添加视觉特效，让玩家在释放技能时获得明显的视觉反馈。

## 背景说明

### 当前问题

1. `SkillManager.ts` 已经在技能释放时 emit 了事件：
   - 轨道炮：`BATTLE_EVENTS.SKILL_ORBITAL_CANNON`，传递 `position`、`radius`、`damage`、`hitCount`
   - 全屏冻结：`BATTLE_EVENTS.SKILL_FREEZE`，传递 `duration`、`targetCount`

2. `EventBus.ts` 已经定义了这两个事件常量

3. `BattleVisualManager.ts` **没有监听**这两个事件，没有技能特效

4. 玩家点击技能按钮后，只有控制台日志，没有视觉反馈

### 设计决策

- 新增 `SkillEffectView.ts` 作为技能视觉特效管理器
- 不将技能特效塞进 `BattleVisualManager.ts`（已有 1239 行，后续技能会变多）
- `SkillEffectView` 只负责视觉，不修改技能伤害、冻结时长、充能逻辑

## 实现计划

### 1. 新增 `assets/scripts/battle/SkillEffectView.ts`

技能视觉特效管理器，负责：
- 监听 `SKILL_ORBITAL_CANNON` 事件，创建轨道炮特效
- 监听 `SKILL_FREEZE` 事件，创建全屏冻结特效
- 监听 `BATTLE_END` 事件，清理所有特效
- 使用 Graphics 动态绘制特效
- 特效节点挂到自身（需在 Cocos 中挂载到 EffectLayer）

#### 轨道炮特效设计

- 预警圆环：红色圆环，提示攻击范围
- 能量光柱：橙黄色垂直光柱，模拟轨道炮落下
- 命中爆炸：白色爆炸圆环，表示命中
- 显示时间：0.6 秒

#### 全屏冻结特效设计

- 冰蓝覆盖：轻量半透明冰蓝色覆盖战斗区域
- 雪花扩散：从中心向外扩散的雪花/冰晶结构
- 冰晶裂纹：斜向冰晶裂纹、短线和少量晶片
- 显示时间：约 1.17 秒，随视觉阶段自然淡出

### 2. 更新文档

- `CHANGELOG.md`：记录本次新增功能
- `docs/handoff/CURRENT_STATE.md`：更新状态
- `PROJECT_MEMORY.md`：添加技能特效说明

## 验收标准

1. 进入战斗后，轨道炮按钮可点击
2. 点击轨道炮后，目标区域出现明显轨道炮视觉特效
3. 轨道炮仍然能造成原有伤害
4. 全屏冻结按钮可点击
5. 点击全屏冻结后，战斗区域出现明显冻结视觉特效
6. 全屏冻结仍然能暂停敌人移动
7. x1 / x2 / x3 / x4 倍速下特效仍然能看清
8. 特效结束后节点自动清理，不残留
9. 战斗结束后特效节点全部清理
10. 不修改 `.scene`
11. 不修改任何战斗数值

## Cocos 人工挂载步骤

**由于不修改 `.scene`，需要用户在 Cocos Creator 中手动挂载 `SkillEffectView` 组件：**

1. 打开 Cocos Creator 编辑器
2. 在场景中找到 `BattleVisualRoot` 节点
3. 展开 `BattleVisualRoot`，找到 `EffectLayer` 子节点
4. 选中 `EffectLayer` 节点
5. 在属性检查器中点击「添加组件」
6. 搜索并添加 `SkillEffectView` 脚本组件
7. 保存场景

**挂载位置说明**：
- `SkillEffectView` 需要挂载到 `EffectLayer` 节点下
- 这样技能特效节点会自动创建为 `EffectLayer` 的子节点
- 战斗结束时 `_clearAll()` 会清理 `EffectLayer` 的所有子节点

## 风险点

1. **特效节点未清理**：已在 `_clearAllEffects()` 中处理，战斗结束时自动清理
2. **倍速兼容**：使用 `update(deltaTime)` 和内部 active effect list 驱动视觉生命周期，不跟随战斗倍速
3. **性能影响**：特效节点生命周期短（0.6-1.0 秒），及时销毁，无性能风险
4. **坐标系**：轨道炮特效使用事件传递的 `position`，全屏冻结特效使用战斗区域中心
