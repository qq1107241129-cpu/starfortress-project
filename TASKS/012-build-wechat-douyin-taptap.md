# TASKS/012-build-wechat-douyin-taptap

## 1. 任务目标

验证 Web、微信小游戏、抖音小游戏和 TapTap 小游戏构建链路，补充构建说明、分包检查和主包体积检查。

## 2. 背景说明

MVP 的平台目标是小游戏方向。该任务不是上线发布，而是验证构建产物能打开、平台适配能降级、主包体积目标可跟踪。

## 3. 涉及文件

- Cocos Creator 构建配置相关文件
- `assets/scripts/platform/*`
- `docs/PLATFORM.md`
- `docs/PUBLISH_MATRIX.md`
- `docs/TECH_DESIGN.md`
- `CHANGELOG.md`

## 4. 允许修改范围

- 更新 Cocos Creator 构建配置。
- 补充平台构建说明。
- 调整资源分包和远程资源配置。
- 修复只影响构建链路的小问题。
- 更新发布矩阵和变更记录。

## 5. 禁止修改范围

- 不接支付。
- 不接服务器。
- 不接 TapTap Android APK 原生 SDK。
- 不新增复杂商业化。
- 不重写业务系统。
- 不为通过构建而绕过 platform adapter。

## 6. 实现假设

- 需要实际 Cocos Creator 3.8.x 环境才能完成最终构建验证。
- 如本地缺少某平台工具，应记录为风险，不伪造验证结果。
- 主包目标为小于 4MB。

## 7. 实现步骤

1. 运行或记录 Web 预览验证方式。
2. 配置微信小游戏构建目标。
3. 配置抖音小游戏构建目标。
4. 配置 TapTap 小游戏转换目标。
5. 检查主包资源与脚本体积。
6. 检查资源分包和远程资源预留。
7. 验证平台能力不可用时能降级。
8. 更新 `docs/PUBLISH_MATRIX.md` 的状态与步骤。
9. 更新 `CHANGELOG.md`。

## 8. 验收标准

1. Web 预览可运行。
2. 微信小游戏构建产物可打开。
3. 抖音小游戏构建产物可打开。
4. TapTap 小游戏转换产物可生成。
5. 主包目标小于 4MB。
6. 平台能力不可用时能降级。
7. `docs/PUBLISH_MATRIX.md` 更新完整。

## 9. 测试方式

- 使用 Cocos Creator Web Preview 运行游戏。
- 使用微信开发者工具打开微信小游戏构建产物。
- 使用抖音开发者工具打开抖音小游戏构建产物。
- 使用 TapTap 小游戏转换工具生成并检查产物。
- 检查构建报告中的主包体积。
- 搜索平台 API，确认业务层没有越权调用。

## 10. 回滚方式

- 恢复构建配置变更。
- 恢复资源分包或远程资源配置。
- 恢复文档和 changelog。
- 清理本任务生成的构建产物。

不要接服务器、支付、原生 SDK 或复杂商业化。不要绕过 platform adapter。若缺少平台工具，请明确记录无法验证的项目和原因，不要声称已验证。完成后输出构建步骤、主包体积、平台降级验证和发布矩阵更新情况。
