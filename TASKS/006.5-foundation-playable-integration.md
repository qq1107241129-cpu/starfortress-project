# 1. 任务目标

本任务目标是把 001~006 已完成的基础系统接起来，形成一个可以在 **Cocos Creator 3.8.x 本地预览中跑通的最小战斗版本**。

本任务不是新增新玩法，而是做阶段性集成验收。

必须验证：

1. 001 项目文档、流程规范、任务规范仍完整可用
2. 002 Platform adapter 能在 WebMock 环境下正常降级
3. 003 ConfigManager 能读取 MVP 配置
4. 004 战斗原型能初始化、开始、计时、结束和结算
5. 005 塔系统能创建塔、搜索目标、攻击敌人、造成伤害
6. 006 敌人和波次系统能读取关卡配置并按波次刷怪
7. 本地 `Battle.scene` 能在 Cocos Creator 中打开和预览
8. 最小战斗流程能跑通

最终希望本地预览流程为：

```txt
打开 assets/scenes/Battle.scene
→ 点击开始或自动启动
→ 初始化 Platform WebMock
→ 初始化 ConfigManager
→ 加载 Stage 1
→ 创建基础塔
→ 按配置生成敌人波次
→ 敌人沿路径移动
→ 塔搜索敌人并攻击
→ 敌人受伤、死亡或到达基地
→ 基地生命值变化
→ 战斗计时推进
→ 战斗结束
→ 输出结算结果
```

# 2. 背景说明

《星垒计划 / Starfortress Project》已经完成了 001~006 的基础开发：

* 001 建立项目文档和 AI 协作规范
* 002 建立平台适配层
* 003 建立核心数据配置
* 004 建立战斗原型
* 005 建立塔系统
* 006 建立敌人和波次系统

但这些系统可能仍处于“脚本存在、模块分散”的状态。
如果没有 Cocos 场景、启动入口、节点绑定和本地预览验证，就无法确认 001~006 是否真的跑通。

此外，当前项目已经完成 Cocos Creator 工程壳迁移。旧的 AI 手写 `Battle.scene` 不再可信，不应恢复或继续使用。
可信的 `Battle.scene` 应由人工在 Cocos Creator 3.8.x 编辑器中创建，并由 Cocos 自动生成 `.scene` 和 `.meta` 文件。

因此，本任务用于在进入 007 肉鸽与主动技能系统之前，建立一个稳定的本地可玩基线。
