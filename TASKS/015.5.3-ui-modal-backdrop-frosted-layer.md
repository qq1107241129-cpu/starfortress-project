# TASKS/015.5.3-ui-modal-backdrop-frosted-layer.md

## 任务目标

塔详情和塔位选择界面不再新增独立 modal backdrop。真实目标已变更为复用肉鸽选择面板的 `styleOuterFrame` 大面板逻辑，让塔详情 / 塔位选择拥有深色半透明大底板和清晰外框。

## 背景说明

### 当前问题

- 塔详情面板和塔位选择面板已置顶，但视觉层次仍偏弱
- 原计划的独立 backdrop / TowerModalBackdrop 方案不再采用，避免增加层级绑定复杂度

### 解决方案

- 复用 `styleOuterFrame()` 绘制深色半透明大底板
- 复用肉鸽大面板的外框表现，保持 UI 风格一致
- 绑定面板和动态 fallback 面板都在显示时应用 `styleOuterFrame()`
- 不新增 Shader / Material / RenderTexture
- 不新增图片资源或第三方依赖

## 允许修改范围

- `assets/scripts/ui/UITheme.ts`
- `assets/scripts/ui/UIStyleUtil.ts`
- `assets/scripts/ui/BattleUI.ts`
- `CHANGELOG.md`
- `docs/handoff/CURRENT_STATE.md`
- `TASKS/015.5.3-ui-modal-backdrop-frosted-layer.md`

## 禁止修改范围

- `assets/scenes/*.scene`
- `assets/scripts/data/*`
- `assets/scripts/platform/*`
- 不修改战斗逻辑、数值配置、技能逻辑
- 不新增 Shader / Material / RenderTexture
- 不引入图片资源、第三方依赖

## 实现计划

### 1. UIStyleUtil.ts

- 保留 `styleOuterFrame(panelNode: Node): void`
- `styleOuterFrame()` 读取面板自身 `UITransform` 尺寸
- 绘制深色半透明背景、外层描边、内层细描边

### 2. BattleUI.ts

- 绑定塔位选择面板显示时调用 `styleOuterFrame(this.towerSelectPanel)`
- 动态塔位选择面板显示时调用 `styleOuterFrame(this._dynamicTowerSelectPanel)`
- 绑定塔详情面板显示时调用 `styleOuterFrame(this.towerDetailPanelRoot)`
- 动态塔详情面板创建时调用 `styleOuterFrame(panel)`
- 显示塔详情时先隐藏塔位选择，显示塔位选择时先隐藏塔详情

### 3. 不再实现的内容

- 不新增 `modalBackdropColor` / `frostedPanelColor`
- 不新增 `styleModalBackdrop()` / `ensureModalBackdrop()`
- 不新增 `_towerModalBackdrop` / `_activeTowerModal`
- 不新增 `TowerModalBackdrop` 节点
- 不使用 `BlockInputEvents`

## 验收标准

1. 塔详情面板有深色半透明大底板和清晰外框
2. 塔位选择面板有深色半透明大底板和清晰外框
3. 绑定面板和动态 fallback 都应用外框逻辑
4. 面板按钮仍可正常点击
5. 显示塔位选择时先隐藏塔详情；显示塔详情时先隐藏塔位选择
6. 不修改 `.scene`
7. 不新增 Shader / Material / RenderTexture
8. 不新增图片资源或依赖
9. 控制台无 015.5.3 相关报错

## 风险点

1. **面板尺寸**：`styleOuterFrame()` 依赖面板自身 `UITransform`，绑定节点尺寸需由 Cocos 人工确认
2. **层级顺序**：面板显示时仍需使用 `_bringNodeToFront()` 置顶
3. **动态 fallback**：动态创建面板需要在创建或显示时重新应用外框样式
