# TASKS/015.5.3-ui-modal-backdrop-frosted-layer.md

## 任务目标

塔详情和塔位选择界面增加背景磨砂遮罩，弹出面板时背后战斗画面被半透明暗化，文字更清晰。

## 背景说明

### 当前问题

- 塔详情面板和塔位选择面板已置顶，但弹出时背景战斗画面仍然很乱
- 面板文字和按钮显示受影响

### 解决方案

- 用半透明深色遮罩模拟磨砂效果
- 遮罩在 BattleVisualRoot 之上、面板之下
- 遮罩阻止点击穿透到战斗区域

## 允许修改范围

- `assets/scripts/ui/UITheme.ts`
- `assets/scripts/ui/UIStyleUtil.ts`
- `assets/scripts/ui/BattleUI.ts`
- `CHANGELOG.md`
- `docs/handoff/CURRENT_STATE.md`
- `TASKS/015.5.3-ui-modal-backdrop-frosted-layer.md`

## 禁止修改范围

- `assets/scenes/*.scene`
- `assets/scripts/data/*`
- `assets/scripts/platform/*`
- 不修改战斗逻辑、数值配置、技能逻辑
- 不新增 Shader / Material
- 不引入图片资源、第三方依赖

## 实现计划

### 1. UITheme.ts 增加遮罩颜色

```typescript
modalBackdropColor: new Color(5, 8, 18, 150),
frostedPanelColor: new Color(15, 20, 40, 220),
```

### 2. UIStyleUtil.ts 增加方法

```typescript
styleModalBackdrop(backdropNode: Node): void
ensureModalBackdrop(parentNode: Node, name: string): Node
```

### 3. BattleUI.ts 增加遮罩逻辑

```typescript
private _towerModalBackdrop: Node | null = null;
private _activeTowerModal: 'select' | 'detail' | null = null;

private _ensureTowerModalBackdrop(): void
private _showTowerModalBackdrop(): void
private _hideTowerModalBackdrop(): void
```

### 4. 层级逻辑

```
先 _bringNodeToFront(this.node)
显示 backdrop
backdrop.setSiblingIndex(parent.children.length - 1)
再显示当前面板
当前面板 setSiblingIndex(parent.children.length - 1)
```

最终顺序：
```
BattleVisualRoot
↓
TowerModalBackdrop
↓
TowerSelectPanel / TowerDetailPanelRoot
```

### 5. 遮罩阻止点击穿透

如果 Cocos 支持 BlockInputEvents，给 TowerModalBackdrop 添加。

### 6. 记录当前打开的 modal 类型

```typescript
private _activeTowerModal: 'select' | 'detail' | null = null;
```

### 7. 显示时互斥

显示塔位选择时，先隐藏塔详情。
显示塔详情时，先隐藏塔位选择。

### 8. 初始化隐藏

游戏开始时隐藏所有面板和遮罩。

## 验收标准

1. 打开塔详情面板时，背后战斗画面被半透明暗化
2. 打开塔位选择面板时，背后战斗画面被半透明暗化
3. 面板按钮仍可正常点击
4. 遮罩不盖住面板
5. 关闭面板后遮罩隐藏
6. 绑定面板和动态 fallback 都支持遮罩
7. 游戏开始时遮罩默认隐藏
8. 不修改 `.scene`
9. 控制台无报错

## 风险点

1. **遮罩层级**：遮罩必须在面板下方，不能盖住按钮
2. **遮罩尺寸**：需要覆盖整个画布或父节点
3. **初始化隐藏**：游戏开始时遮罩必须默认隐藏
4. **点击穿透**：如果支持 BlockInputEvents，阻止点击穿透
