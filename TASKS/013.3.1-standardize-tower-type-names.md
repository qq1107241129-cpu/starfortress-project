# TASKS/013.3.1-standardize-tower-type-names.md

## 任务目标

统一 4 种塔的 id 和 type 命名，全部使用 `_tower` 后缀，使 id 和 type 保持一致。

## 背景说明

塔配置中的 id 和 type 使用不同命名风格：
- 旧 id: tower_machinegun, tower_cannon, tower_ice, tower_electric
- 旧 type: machinegun, cannon, ice, electric

统一为同一套命名：
- 新 id: machinegun_tower, cannon_tower, ice_tower, electric_tower
- 新 type: machinegun_tower, cannon_tower, ice_tower, electric_tower

## 统一命名规则

| 旧 id | 旧 type | 新 id/type |
|-------|---------|------------|
| tower_machinegun | machinegun | machinegun_tower |
| tower_cannon | cannon | cannon_tower |
| tower_ice | ice | ice_tower |
| tower_electric | electric | electric_tower |

## 允许修改范围

- `assets/scripts/data/TowerConfig.ts`（id 和 type 字段）
- `assets/scripts/bootstrap/GameBootstrap.ts`（测试放塔 towerId）
- `assets/scripts/battle/TowerView.ts`（configId 判断改为精确匹配）
- `assets/scripts/battle/AttackEffectView.ts`（getTowerAttackColor switch case）
- `assets/scripts/battle/TowerManager.ts`（_executeAttack switch case）
- `assets/scripts/ui/BattleUI.ts`（_showTowerSelectPanel switch case）
- `assets/scripts/data/SkillConfig.ts`（肉鸽强化 target 字段）
- `TASKS/013.3-tower-attack-projectile-effects.md`（示例代码）
- `TASKS/013.3.1-standardize-tower-type-names.md`（本文件）
- `CHANGELOG.md`
- `docs/handoff/CURRENT_STATE.md`

## 禁止修改范围

- `assets/scenes/*.scene`（.scene 文件属于用户人工维护）
- 不修改战斗数值
- 不修改攻击频率
- 不修改目标选择逻辑
- 不引入新依赖

## 验收标准

代码层面：

1. TowerConfig.id 和 type 统一为 `machinegun_tower | cannon_tower | ice_tower | electric_tower`
2. 所有 switch case 使用新类型名
3. SkillConfig.target 使用新类型名
4. GameBootstrap.ts 使用新 id
5. TowerView.ts 使用精确判断
6. TypeScript 无明显类型错误
7. 未修改 .scene 文件

Web 预览人工验收：

1. 可以打开塔选择面板
2. 可以放置 4 种塔
3. 4 种塔都能攻击敌人
4. 肉鸽强化能正确应用到对应塔类型

1. 在 Cocos Creator 中运行 Web 预览
2. 开始战斗，放置 4 种不同塔
