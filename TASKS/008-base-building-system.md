# TASKS/008-base-building-system

## 1. 任务目标

实现基地经营建筑系统，包括基地核心、研究所、矿场、能源反应堆、工厂的显示、升级、消耗、属性加成和保存。

## 2. 背景说明

基地经营是塔防收益的成长出口，也是放置收益和转生条件的基础。MVP 只做 5 个建筑，不加入居民区、商店、仓库等后续建筑。

## 3. 涉及文件

- `assets/scripts/base/BaseManager.ts`
- `assets/scripts/base/BuildingManager.ts`
- `assets/scripts/core/SaveManager.ts`
- `assets/scripts/data/BuildingConfig.ts`
- `assets/scripts/ui/BuildingUI.ts`
- `docs/GAME_DESIGN.md`
- `docs/TECH_DESIGN.md`
- `CHANGELOG.md`

## 4. 允许修改范围

- 新增或更新基地与建筑管理脚本。
- 接入建筑配置和存档字段。
- 创建基础建筑升级 UI 逻辑。
- 更新文档和变更记录。

## 5. 禁止修改范围

- 不新增 MVP 外建筑。
- 不实现复杂基地摆放。
- 不实现居民满意度、贸易、仓库等后续系统。
- 不接广告、支付或服务器。
- 不重构战斗系统无关逻辑。

## 6. 实现假设

- 建筑等级从 1 开始。
- 升级消耗经营币或战斗金币，具体以配置为准。
- 建筑效果以数值加成形式暴露给其他系统。

## 7. 实现步骤

1. 定义 5 个建筑的等级、成本和效果。
2. 实现建筑数据读取和默认值。
3. 实现建筑升级条件检查。
4. 实现升级消耗资源。
5. 实现升级后效果刷新。
6. 接入存档保存和读取。
7. 创建基础建筑 UI 逻辑，用于显示等级、成本和升级按钮。
8. 更新文档与 changelog。

## 8. 验收标准

1. 建筑可显示。
2. 建筑可升级。
3. 升级消耗资源。
4. 升级后产出或属性提升。
5. 建筑数据可保存和读取。
6. 只包含 MVP 五个建筑。

## 9. 测试方式

- Web 预览打开建筑界面。
- 升级每个建筑并观察资源扣除。
- 重启预览或模拟读档，确认建筑等级保留。
- 检查建筑效果是否能被相关系统读取。

## 10. 回滚方式

- 恢复基地和建筑相关脚本。
- 恢复存档字段改动。
- 恢复建筑配置、UI 和文档。

## 11. 给执行 Agent 的执行提示词

你是《星垒计划》的执行工程师。当前任务是基地经营建筑系统。请只实现基地核心、研究所、矿场、能源反应堆、工厂的显示、升级、消耗、效果和保存。

不要新增其他建筑、基地摆放、服务器、支付或广告。完成后输出建筑升级和存档验证方式。
