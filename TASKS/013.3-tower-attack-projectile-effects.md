# TASKS/013.3-tower-attack-projectile-effects.md

## 任务目标

为 4 种 MVP 防御塔增加不同攻击弹道效果，让玩家一眼能看出不同塔的攻击方式。

## 背景说明

当前 Web 预览中所有防御塔攻击效果都是同一种线条，视觉区分度太低。需要根据防御塔类型显示不同攻击弹道：
- 机枪塔：快速小子弹 / 短弹道
- 炮塔：炮弹飞行 / 命中爆炸
- 冰塔：冰蓝色冰锥 / 冰冻冲击
- 电塔：闪电链 / 折线电弧

## 实现计划

### 1. 扩展 AttackEffectView.ts

添加 4 种塔的专属效果方法：

```typescript
// 机枪塔：快速小圆点弹道
playBulletEffect(fromPos, toPos): void
- 颜色：黄白色 (255, 240, 180)
- 形状：小圆点（半径 3-4）
- 持续时间：0.08 ~ 0.15 秒
- 从塔位置向敌人位置快速移动

// 炮塔：炮弹飞行 + 命中爆炸
playShellEffect(fromPos, toPos): void
- 颜色：橙红色 (255, 120, 50)
- 形状：圆形炮弹（半径 6-8）
- 持续时间：0.2 ~ 0.35 秒
- 命中后显示爆炸圆环效果

// 冰塔：冰蓝色冰锥 + 冰冻冲击
playIceShardEffect(fromPos, toPos): void
- 颜色：冰蓝色 (150, 220, 255)
- 形状：菱形 / 三角冰锥
- 持续时间：0.18 ~ 0.28 秒
- 命中后显示冰蓝色扩散圆环

// 电塔：折线闪电
playLightningEffect(fromPos, toPos): void
- 颜色：蓝紫色 (180, 120, 255)
- 形状：2-4 段随机折线
- 持续时间：0.08 ~ 0.12 秒
- 瞬发，不需要飞行
```

### 2. 修改 BattleVisualManager._createAttackEffect

根据 towerType 调用对应的 AttackEffectView 方法：

```typescript
private _createAttackEffect(towerType, fromPos, toPos): void {
    // 创建 AttackEffectView 节点
    // 根据 towerType 调用对应方法
    switch (towerType) {
        case 'machinegun_tower':
            effectView.playBulletEffect(fromPos, toPos);
            break;
        case 'cannon_tower':
            effectView.playShellEffect(fromPos, toPos);
            break;
        case 'ice_tower':
            effectView.playIceShardEffect(fromPos, toPos);
            break;
        case 'electric_tower':
            effectView.playLightningEffect(fromPos, toPos);
            break;
    }
}
```

## 验收标准

Web 预览中必须确认：

1. 机枪塔攻击不是普通长线，而是快速小圆点弹道
2. 炮塔攻击是炮弹，并且命中有小爆炸效果
3. 冰塔攻击是冰蓝色冰锥 / 冰晶效果
4. 电塔攻击是蓝紫色折线闪电
5. 4 种塔攻击视觉明显不同
6. 攻击效果不会长期残留
7. 大量攻击时帧率没有明显下降
8. 战斗伤害、攻击频率、敌人移动逻辑没有被改坏
9. 未修改 `.scene` 文件

## 测试方式

1. 在 Cocos Creator 中运行 Web 预览
2. 开始战斗，放置 4 种不同塔
3. 观察每种塔的攻击弹道是否不同
4. 确认攻击效果持续时间合理
5. 确认大量攻击时性能正常

## 风险点

1. Graphics 绘制性能：大量攻击时可能影响帧率
   - 缓解：控制特效持续时间，及时销毁节点
2. 节点堆积：如果销毁逻辑有 bug，可能导致节点堆积
   - 缓解：在 update 中检查生命周期，超时自动销毁
3. 坐标系问题：特效位置需要正确转换
   - 缓解：复用现有的坐标转换逻辑
