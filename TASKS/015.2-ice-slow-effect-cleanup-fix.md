# TASKS/015.2-ice-slow-effect-cleanup-fix.md

## 任务目标

修复冰塔减速特效在敌人死亡时有概率残留原地不消失的 bug。

## 背景说明

### 问题描述

冰塔攻击敌人时会创建冰蓝色光环减速特效。当敌人在减速期间死亡时，有概率减速特效会留在原地不消失。

### 排查结论

代码中 `_onEnemyDeath` 已调用 `_removeSlowEffect(enemyId)` 清理减速特效，但存在时序风险：
- 如果 `_onEnemyDeath` 因某种原因未执行，或 `_removeSlowEffect` 未能正确清理，减速特效就会残留
- `_syncSlowEffectPositions` 只遍历存活敌人，不会处理死敌人的减速特效

### 修复方案

在 `_syncSlowEffectPositions` 中增加兜底清理逻辑：
- 遍历 `_slowEffects` Map
- 如果 enemyId 不在存活敌人列表中，立即 `_removeSlowEffect(enemyId)`
- 如果 slowNode 无效，也从 `_slowEffects` 删除
- 对存活敌人继续同步减速特效位置

## 实现计划

### 1. 修改 `_syncSlowEffectPositions` 方法

```typescript
private _syncSlowEffectPositions(): void {
    if (!this._battleManager) return;

    const aliveEnemies = this._battleManager.getAliveEnemies();
    const aliveIds = new Set<string>();
    for (const enemy of aliveEnemies) {
        aliveIds.add(enemy.getId());
    }

    // 兜底清理：遍历 _slowEffects，清理不在存活列表中的特效
    const toRemove: string[] = [];
    for (const [enemyId, slowNode] of this._slowEffects) {
        if (!aliveIds.has(enemyId) || !slowNode || !slowNode.isValid) {
            toRemove.push(enemyId);
        }
    }
    for (const enemyId of toRemove) {
        this._removeSlowEffect(enemyId);
    }

    // 正常同步存活敌人的减速特效位置
    for (const enemy of aliveEnemies) {
        const enemyId = enemy.getId();
        const slowNode = this._slowEffects.get(enemyId);
        if (slowNode && slowNode.isValid) {
            const position = enemy.getPosition();
            slowNode.setPosition(position.x, position.y, 0);
        }
    }
}
```

### 2. 确认 `_removeSlowEffect` 正确性

当前实现：
```typescript
private _removeSlowEffect(enemyId: string): void {
    const slowNode = this._slowEffects.get(enemyId);
    if (slowNode && slowNode.isValid) {
        slowNode.destroy();
    }
    this._slowEffects.delete(enemyId);
}
```

1. **性能影响**：每帧遍历 `_slowEffects` Map，但 Map 通常很小（最多几十个条目），性能影响可忽略
