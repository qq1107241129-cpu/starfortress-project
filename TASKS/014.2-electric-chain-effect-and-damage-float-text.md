# TASKS/014.2-electric-chain-effect-and-damage-float-text.md

## 任务目标

1. 修复电弧弹射没有特效：电塔弹射时，每段弹射路径都显示蓝紫色折线闪电
2. 新增伤害飘字：敌人受到伤害时，在敌人身上显示伤害数字飘字

## 背景说明

### 电弧弹射特效问题

当前电塔攻击链路：
- `TowerManager._executeAttack()` → `ProjectileManager.createChain(towerPos, targetId, attack, chainCount)`
- `ProjectileManager._onHit()` → `target.takeDamage(proj.damage)` → `_chainAttack()`
- `_chainAttack()` 循环 `chainRemaining` 次，找最近敌人，`applyDamage`，记录 `hits`

当前电弧特效链路：
- `TowerManager._executeAttack()` 发出 `TOWER_ATTACK` 事件（只有 `towerPosition` 和 `targetPosition`）
- `BattleVisualManager._onTowerAttack()` 创建 `AttackEffectView.playLightningEffect(from, to)`
- 只创建了一段电弧（塔→第一个敌人）

问题原因：
- `TOWER_ATTACK` 事件只传了第一个目标位置
- `_chainAttack()` 在 `ProjectileManager` 内部执行，没有发出任何事件
- `BattleVisualManager` 不知道弹射发生了，无法创建后续电弧

### 伤害飘字需求

当前敌人受到伤害时没有任何视觉反馈。需要在敌人身上显示伤害数字飘字，让玩家直观看到每次攻击造成的伤害。

## 电弧弹射特效修复方案

### 问题分析

`ProjectileManager._chainAttack()` 执行弹射时，只调用 `chainTarget.takeDamage(chainDamage)` 和记录 `hits`，没有发出任何可视化事件。

### 修复方案

1. 在 `EventBus.ts` 新增 `CHAIN_HIT` 事件
2. 在 `ProjectileManager._chainAttack()` 中，每次弹射命中时发出 `CHAIN_HIT` 事件，传递 `fromPosition` 和 `toPosition`
3. 在 `BattleVisualManager` 中监听 `CHAIN_HIT` 事件，为每段弹射创建 `AttackEffectView.playLightningEffect(from, to)`

### 事件设计

```typescript
// EventBus.ts 新增
CHAIN_HIT: 'battle:chain_hit',

// 事件数据
{
  fromPosition: { x: number; y: number },  // 弹射起点（上一个敌人位置）
  toPosition: { x: number; y: number },    // 弹射终点（当前敌人位置）
  chainIndex: number,                       // 弹射序号（0=第一次弹射）
  damage: number,                           // 实际伤害值
}
```

### 电弧效果要求

- 颜色：蓝紫 / 电光色（复用 `AttackEffectView.playLightningEffect`）
- 形态：折线闪电（已有 `_createLightningPoints` 实现）
- 生命周期：0.11s（复用现有值）
- 已接入倍速（`AttackEffectView` 已监听 `BATTLE_SPEED_CHANGE`）

## 伤害飘字方案

### 事件设计

```typescript
// EventBus.ts 新增
DAMAGE_NUMBER_SHOW: 'battle:damage_number_show',

// 事件数据
{
  damage: number,                           // 实际伤害值
  position: { x: number; y: number },       // 敌人位置
  towerType?: string,                       // 塔类型（用于区分颜色）
}
```

### 事件发出位置

在 `ProjectileManager` 中，每次调用 `enemy.takeDamage()` 后发出 `DAMAGE_NUMBER_SHOW` 事件：

1. `_onHit()` 命中主目标时
2. `_onHit()` 范围伤害命中每个敌人时
3. `_chainAttack()` 弹射命中每个敌人时

### 飘字实现

在 `BattleVisualManager` 中实现，不新增脚本文件：

1. 监听 `DAMAGE_NUMBER_SHOW` 事件
2. 动态创建 `Label` 节点，挂在 `effectLayer` 下
3. `update()` 中处理上浮、淡出、销毁

### 飘字样式

| 塔类型 | 颜色 |
|---|---|
| machinegun_tower | 白色 / 浅黄色 |
| cannon_tower | 橙色 |
| ice_tower | 冰蓝色 |
| electric_tower | 蓝紫色 |
| 默认 | 白色 |

### 飘字动画参数

- 初始位置：敌人位置上方 y+30
- 移动：向上 50 像素
- 生命周期：0.7s
- 透明度：从 255 渐变到 0
- 字号：18~20
- 前缀：`-`（例如 `-12`）

### 倍速兼容

飘字使用 `deltaTime * battleSpeed` 更新生命周期，确保 x4 倍速下飘字不会瞬间消失。

## 验收标准

Web 预览人工验收：

1. 电塔攻击第一个敌人时能看到蓝紫色电弧
2. 电塔发生弹射时，后续敌人之间也能看到电弧
3. 电弧不是普通直线，而是折线闪电效果
4. 每个被命中的敌人身上显示伤害飘字
5. 炮塔范围伤害命中多个敌人时，多个敌人都显示伤害飘字
6. 冰塔命中敌人时显示伤害飘字
7. 普通机枪塔命中敌人时显示伤害飘字
8. x1/x2/x3/x4 倍速下，电弧和飘字表现正常
9. 飘字会自动上浮并消失，不残留节点
10. 没有控制台报错
11. 未修改 `.scene`
12. 未修改战斗数值配置

## 测试方式

1. 在 Cocos Creator 中运行 Web 预览
2. 进入战斗，放置电塔
3. 观察电塔攻击时是否有电弧特效
4. 观察弹射时是否有多段电弧
5. 观察每个被命中敌人是否显示伤害飘字
6. 放置其他塔（机枪、炮塔、冰塔），确认飘字正常
7. 切换倍速（x2/x3/x4），确认电弧和飘字跟随倍速
8. 确认飘字自动消失，不残留节点
9. 确认没有控制台报错

## 风险点

1. 链式攻击事件需要传递准确的 from/to 位置 — 缓解：从 ProjectileState 和 EnemyController 获取
2. 伤害飘字需要使用实际扣血值（考虑护甲）— 缓解：从 takeDamage 后的实际值获取
3. 大量飘字可能影响性能 — 缓解：控制生命周期 0.7s，及时销毁
4. x4 倍速下飘字需要跟随倍速 — 缓解：使用 deltaTime * battleSpeed
5. 敌人死亡后飘字位置不再更新 — 缓解：飘字创建后独立于敌人，只记录初始位置
