## 实现步骤

### 步骤 1：调整布局常量

```typescript
// 标题（固定顶部）
TITLE_Y = 420
TITLE_FONT_SIZE = 36

// 返回按钮（固定底部）
BACK_BTN_Y = -420
BACK_BTN_WIDTH = 180
BACK_BTN_HEIGHT = 56

// 滚动区域
SCROLL_AREA_Y = 20
SCROLL_AREA_HEIGHT = 720
STAGE_BTN_WIDTH = 480
STAGE_BTN_HEIGHT = 96
STAGE_BTN_GAP = 16

// 关卡按钮内部文字
STAGE_TITLE_Y = 28
STAGE_TITLE_FONT = 24
STAGE_DESC_Y = 0
STAGE_DESC_FONT = 16
STAGE_STATUS_Y = -28
STAGE_STATUS_FONT = 18

// 移除 MAX_VISIBLE_STAGES 限制
```

### 步骤 2：重写 _createUI()

1. 创建半透明背景遮罩（不变）
2. 创建 panelContainer（560 x 980，不变）
3. 绘制面板背景（不变）
4. 创建标题（y=420，不变）
5. 创建返回按钮 → 移到 y=-420
6. 创建 ScrollView + Mask + Content 结构：
   - ScrollViewNode：挂在 panelContainer 下，位置 (0, SCROLL_AREA_Y)，尺寸 (STAGE_BTN_WIDTH, SCROLL_AREA_HEIGHT)
   - Mask 组件：RECT 类型裁剪滚动区域
   - Content 子节点：ScrollView 的内容容器，尺寸根据关卡数量动态计算

### 步骤 3：使用 Cocos ScrollView API

```typescript
import { ScrollView, Mask } from 'cc';

// 创建 ScrollView 节点
const scrollNode = new Node('ScrollView');
scrollNode.addComponent(UITransform).setContentSize(STAGE_BTN_WIDTH, SCROLL_AREA_HEIGHT);
scrollNode.setPosition(0, SCROLL_AREA_Y, 0);

// 添加 Mask
const mask = scrollNode.addComponent(Mask);
mask.type = Mask.Type.RECT;

// 创建 Content 节点
const content = new Node('Content');
content.addComponent(UITransform);
scrollNode.addChild(content);

// 添加 ScrollView 组件
const scrollView = scrollNode.addComponent(ScrollView);
scrollView.content = content;
scrollView.horizontal = false;
scrollView.vertical = true;
scrollView.bounceDuration = 0.2;
scrollView.inertia = true;
scrollView.brake = 0.5;
scrollView.elastic = true;

panelContainer.addChild(scrollNode);
```

### 步骤 4：重写 _updateStageButtons()

1. 清除旧按钮（清理 Content 子节点）
2. 遍历所有 StageConfig（不再限制 MAX_VISIBLE_STAGES）
3. 计算 Content 高度：`stageCount * (BTN_HEIGHT + GAP) - GAP`
4. 设置 Content 锚点为顶部（anchorY = 1），从上往下排列
5. 每个按钮设置位置

### 步骤 5：实现默认滚动到推荐关卡

```typescript
// 计算推荐 index
const recommendedIndex = Math.min(highestStage, stageConfigs.length - 1);

// 计算需要滚动的偏移量
const itemHeight = STAGE_BTN_HEIGHT + STAGE_BTN_GAP;
const scrollOffset = recommendedIndex * itemHeight;

// 限制最大滚动
const contentHeight = stageConfigs.length * itemHeight - STAGE_BTN_GAP;
const maxScroll = Math.max(0, contentHeight - SCROLL_AREA_HEIGHT);
const targetPercent = maxScroll > 0 ? Math.min(scrollOffset / maxScroll, 1) : 0;

// 使用 ScrollView API
scrollView.scrollToPercentVertical(targetPercent, 0.3, true);

// 兜底：直接设置 content.position
if (targetPercent > 0) {
    const contentPos = content.position;
    content.setPosition(contentPos.x, targetPercent * maxScroll, contentPos.z);
}
```

### 步骤 6：修复关卡按钮内部文字布局

调整文字位置，避免重叠：
- 标题：y = +28，字号 24，左对齐
- 描述：y = 0，字号 16，左对齐
- 状态：y = -28，字号 18，居中

### 步骤 7：清理逻辑增强

- refresh() 前清理 Content 的所有子节点
- _clearStageButtons() 同时清理 MoreHint 节点
- ScrollView / Mask / Content 只初始化一次（_createUI 中创建）
- 关卡按钮每次 refresh 重建

### 步骤 8：移除 _createMoreHint()

所有关卡都能通过滚动查看，不再需要"更多关卡后续开放"提示。

## 风险点

1. **ScrollView API 稳定性**：Cocos Creator 3.8.x 的 ScrollView API 可能有坑
   - 缓解：先尝试 ScrollView API，不生效时用直接设置 content.position 的方式兜底

2. **Mask 裁剪**：ScrollView 自带 Mask，但需要正确配置 RECT 类型
   - 缓解：确保 ScrollViewNode 有 UITransform 且 contentSize 正确

3. **触摸事件冲突**：ScrollView 的拖动可能与背景遮罩的点击关闭事件冲突
   - 缓解：背景遮罩在 ScrollView 之外，不冲突

4. **Content 锚点**：Cocos ScrollView 的 Content 锚点影响滚动行为
   - 缓解：设置 Content 的 anchorY = 1（顶部对齐），从上往下排列按钮

5. **默认滚动失败**：如果滚动 API 不生效，面板可能显示在第 1 关位置
   - 缓解：面板仍然可用，只是需要手动滚动
