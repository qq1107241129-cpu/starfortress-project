# 素材获取与美术规范

## 1. 美术方向

- 高级精细像素风。
- 科幻前线基地。
- 异星防御。
- 机械塔防。
- 深蓝钢灰为结构色。
- 青色能量光、紫色科技光作为点缀。
- 轻 UI 质感。
- 清晰轮廓。
- 透明背景素材。

## 2. 素材阶段规划

### 阶段 1：原创占位素材

目标是快速验证玩法闭环。可使用 AI 生成、手绘简化像素、简单形状或临时 UI，但必须保持统一风格和命名规范。

### 阶段 2：可商用素材包筛选

用于替换低质量占位素材，提升整体观感。必须确认授权范围支持商业项目、小游戏平台、二次修改和长期使用。

### 阶段 3：正式美术外包

在核心玩法确认后，输出统一美术需求，外包正式塔、敌人、建筑、UI、图标和特效。

### 阶段 4：发布前版权归档

所有外部素材必须保存授权证明、购买记录、授权协议、作者来源和使用范围说明。

## 3. 占位素材方案

- 允许使用 AI 生成原创方向占位素材。
- 允许使用自制简化像素块和 Cocos 基础形状。
- 允许使用临时 UI 面板和按钮。
- 不追求最终品质，但必须统一风格。
- 占位素材应命名规范，方便后续替换。

## 4. 可商用素材包筛选标准

必须满足：

1. 明确允许商业使用。
2. 明确允许在小游戏、移动端或数字游戏中使用。
3. 明确允许项目内修改、裁剪、重绘或重新打包。
4. 不要求开源项目强制公开源码。
5. 不含第三方 IP、商标、角色或品牌元素。
6. 授权证明可长期保存。

不建议使用：

- 来源不明的免费素材。
- 只允许个人学习使用的素材。
- 授权条款模糊的素材。
- 明显模仿知名商业游戏的素材包。

## 5. 正式美术外包阶段

外包前必须准备：

- 游戏定位。
- 画面参考，但不得要求复刻具体商业作品。
- 塔、敌人、建筑、UI、图标清单。
- 尺寸和透明 PNG 要求。
- 动画帧数要求。
- 命名规范。
- 版权归属与商用授权合同。

外包验收重点：

- 风格统一。
- 缩小后轮廓清晰。
- 竖屏下可读。
- 不含文字水印。
- 不含商业 IP 混淆元素。

## 6. 素材目录规范

建议目录：

```txt
assets/
├─ art/
│  ├─ towers/
│  ├─ enemies/
│  ├─ buildings/
│  ├─ ui/
│  ├─ icons/
│  ├─ effects/
│  └─ placeholders/
└─ remote/
   ├─ towers/
   ├─ enemies/
   └─ ui/
```

大资源必须预留分包或远程资源方案。

## 8. 版权注意事项

- 所有外部素材必须保存授权证明。
- AI 生成素材也要保留提示词、生成时间和工具来源。
- 不得使用无法确认授权的网络图片。
- 不得使用商标、Logo 或知名角色变体。
- 不得使用可能导致平台审核风险的素材。

## 9. 禁止事项

- 不要复刻已有游戏素材。
- 不要使用商业 IP。
- 不要直接模仿弹壳特攻队、保卫萝卜等具体角色、UI、怪物和塔。
- 不要复制其他游戏的按钮、图标、技能特效和怪物轮廓。
- 不要把未授权素材放入主包。
- 不要使用带水印素材。
