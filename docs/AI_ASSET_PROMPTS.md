# AI 像素占位素材生成方案

本文件用于生成《星垒计划》的原创占位素材。生成结果只作为占位或美术方向参考，进入正式发布前必须进行版权复核和必要的人工精修。

## 1. 统一美术规范

```txt
高级精细像素风，科幻前线基地，异星防御，机械塔防，深蓝钢灰结构，青色能量光，紫色科技光，轻 UI 质感，清晰轮廓，透明背景素材，适合竖屏小游戏。
```

## 2. 通用正向提示词

```txt
原创科幻塔防小游戏素材，高级精细像素风，轻微 45 度俯视视角，深蓝钢灰机械结构，青色和紫色能量光点缀，轮廓清晰，缩小后可辨认，适合竖屏小游戏，透明 PNG 背景，不包含文字，不包含水印。
```

## 3. 通用负向约束

```txt
不要文字，不要水印，不要 Logo，不要商标，不要真实品牌，不要商业 IP，不要模仿已有游戏角色，不要模仿弹壳特攻队，不要模仿保卫萝卜，不要复制已有游戏 UI，不要过度写实，不要复杂背景，不要低清晰度，不要大面积模糊，不要裁切主体。
```

## 4. 透明 PNG 要求

- 背景必须透明。
- 不包含投影到非透明背景上的脏边。
- 主体居中，四周保留 4 到 8 像素安全边距。
- 输出后检查 alpha 通道。
- 临时占位可为单帧，后续动画再拆帧。

## 5. 尺寸建议

| 类型 | 建议尺寸 |
| --- | --- |
| 小型塔 | 64x64 |
| 中型塔 | 72x72 或 80x80 |
| 小怪 | 64x64 |
| 重甲敌人 | 96x96 |
| 小 Boss | 160x160 |
| 建筑 | 160x160 或 256x256 |
| UI 图标 | 64x64 |
| UI 按钮九宫格 | 96x48 或 128x64 |
