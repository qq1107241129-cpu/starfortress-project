# 审查清单

本清单用于 Codex 审查执行 Agent 的 diff。审查时先列问题和风险，再给总结。

## 1. 任务符合性检查

- 是否符合当前 `TASKS/*.md`。
- 是否完成任务目标。
- 是否遗漏验收标准。
- 是否把多个任务混在一起。
- 是否擅自扩大 MVP 范围。

## 2. 越权修改检查

- 是否修改了当前任务未授权文件。
- 是否删除已有功能。
- 是否重构无关代码。
- 是否引入不必要依赖。
- 是否修改业务代码以外的构建、资源或场景文件而未说明。

## 3. 平台 API 检查

- 业务代码是否直接调用 `wx`、`tt`、`tap`、`TapSDK`。
- 平台 API 是否只出现在 `assets/scripts/platform/`。
- 所有平台能力是否通过 platform adapter。
- `WebMockPlatform` 是否可运行。
- 平台能力失败时是否降级。

## 4. Cocos 项目结构检查

- 是否破坏 Cocos Creator 3.8.x 项目结构。
- 脚本、资源、场景、Prefab 是否放在合理位置。
- TypeScript 是否可编译。
- Cocos 组件职责是否清晰。
- 是否避免无法被 Cocos 识别的组织方式。

## 5. 包体风险检查

- 是否影响主包小于 4MB 的目标。
- 是否引入大型依赖。
- 是否把大资源放入主包。
- 是否预留分包和远程资源。
- 是否有无用资源、重复资源或临时素材未隔离。

## 6. 性能风险检查

- 是否存在频繁实例化和销毁。
- 是否存在每帧全局查找。
- 是否存在大量临时对象分配。
- 是否存在不必要的复杂寻路或物理计算。
- 是否能在低端移动设备上维持可接受表现。

## 7. 文档同步检查

- 是否更新 `CHANGELOG.md`。
- 是否更新 `PROJECT_MEMORY.md`。
- 是否更新当前任务文件中的实现假设或备注。
- 是否同步更新 `docs/TECH_DESIGN.md`、`docs/PLATFORM.md`、`docs/PUBLISH_MATRIX.md`。
- 如果未更新，是否说明原因。

## 8. MVP 范围检查

- 是否仍只做 10 关。
- 是否仍只做 4 种 MVP 塔。
- 是否仍只做 5 种 MVP 敌人。
- 是否仍只做 5 个 MVP 建筑。
- 是否仍只做 2 个主动技能。
- 是否仍只做 5 个永久技能。
- 是否避免服务器、支付、复杂商业化和原生 APK。

## 9. Git 提交前检查

人工提交前确认：

```txt
[ ] 已执行 git status
[ ] 已执行 git diff
[ ] Codex 审查通过
[ ] 必须修复项已处理
[ ] Web 预览验证完成或说明无法验证
[ ] 三端小游戏影响已说明
[ ] CHANGELOG.md 已更新
[ ] PROJECT_MEMORY.md 已更新或说明无需更新
[ ] 没有业务代码直接调用平台 API
[ ] 没有越权修改
```
